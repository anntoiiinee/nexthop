Configurer trois switches à la main, c'est rapide. En configurer trois cents, sans erreur, de
façon identique, et savoir à tout moment ce qui a changé et pourquoi, c'est une autre histoire.
L'automatisation réseau (on parle aussi de **NetOps** ou de **NetDevOps**) applique au réseau les
méthodes des développeurs : du code versionné, des tâches répétables et des changements tracés.

## Le fil rouge : l'équipe réseau s'outille

L'entreprise des formations précédentes a grandi, son équipe réseau aussi. Elle veut arrêter de se
connecter équipement par équipement, et se doter d'une chaîne d'outils complète :

## Au programme

| Chapitre | Ce que vous saurez faire |
|---|---|
| **1. Python pour le réseau** | Se connecter à des équipements avec Netmiko, exploiter des sorties JSON, travailler en parallèle |
| **2. Ansible pour le réseau** | Écrire un inventaire et des playbooks, comprendre l'idempotence, protéger ses secrets avec Vault |
| **3. Sauvegardes GitOps** | Sauvegarder chaque jour toutes les configurations dans Git avec un pipeline GitLab CI |
| **4. Rotation du compte de secours** | Supprimer le compte admin par défaut, créer un compte de secours unique et le faire tourner automatiquement |
| **5. Conventions de nommage et IPAM** | Fixer les règles de nommage et le plan d'adressage, et les faire vérifier par la CI |
| **6. NetBox, source de vérité** | Modéliser son réseau dans NetBox et en tirer inventaires et configurations |
| **7. Arista AVD** | Générer, documenter et valider les configurations d'une fabric à partir d'un modèle YAML |

## Prérequis

- La formation [Fondamentaux](/formations/fundamentals) ; le [routage dynamique](/formations/routing) aide pour le chapitre AVD.
- Être à l'aise avec un terminal Linux (`cd`, `ls`, éditer un fichier).
- Aucune expérience de Python ni d'Ansible n'est nécessaire : on part des bases.

<Callout type="note">
Tous les scripts de la formation sont de vrais fichiers, regroupés dans le lab `netops` : trois
switches Arista cEOS, un inventaire partagé par Python et Ansible, et les scripts des chapitres.
Le code affiché dans les chapitres est exactement celui que vous téléchargez.
</Callout>
