This course lays the foundations that every other topic on this site builds on: BGP,
EVPN-VXLAN, firewalls or automation. **No prerequisites**: we start from scratch, and each
chapter builds on the previous one.

## The running example: a branch office network

Rather than isolated examples, we build the network of a small branch office connected to its
headquarters, chapter after chapter. By the end of the course, you will be able to explain every
frame and every packet that crosses it.

## What you will learn

| Chapter | What you will be able to do |
|---|---|
| **1. The OSI model** | Place a problem or a device in the layers, understand encapsulation |
| **2. Ethernet and MAC addresses** | Read a frame, explain how a switch learns and forwards |
| **3. VLANs** | Segment a network, configure access ports and 802.1Q trunks |
| **4. Spanning Tree** | Understand why a loop is fatal and how STP prevents it |
| **5. Link aggregation** | Bundle links into a port-channel with LACP, connect a server to two switches with MLAG / vPC |
| **6. LLDP and CDP** | Know what is plugged into each port, check the cabling |
| **7. IPv4 addressing and subnetting** | Compute network, broadcast and host range, build a VLSM addressing plan |
| **8. ARP** | Explain how an IP becomes a MAC, read an ARP cache, spot spoofing |
| **9. Static routing** | Read a routing table, configure routes and troubleshoot with ping and traceroute |
| **10. TCP and UDP** | Read a SYN, SYN-ACK, ACK handshake, tell *refused* from *timeout*, choose between TCP and UDP |
| **11. Encryption** | Explain public and private keys, signatures and Diffie-Hellman with Alice and Bob, understand why certificates are needed |

## How to follow the course

- **Read in order**: each chapter reuses the concepts of the previous one.
- **Hover over dotted-underlined terms** (like <Term id="vlan" />): their definition shows up.
- **Practice** with the [tools](/en/tools): subnet calculator, VLSM planner and quiz.
- **Rebuild the lab** of the static routing chapter, then the TCP capture of the last chapter: all it takes is a PC, Docker and ContainerLab.

<Callout type="note">
Configuration examples are given for **Arista EOS** and **Cisco IOS**: both syntaxes are very
close, and they are the ones you will meet most often in the enterprise.
</Callout>
