Configuring three switches by hand is quick. Configuring three hundred, without mistakes, identically,
and knowing at any time what changed and why, is another story. Network automation (also called
**NetOps** or **NetDevOps**) brings developer practices to the network: versioned code, repeatable
tasks and traceable changes.

## The common thread: the network team gets tooled up

The company from the previous courses has grown, and so has its network team. It wants to stop logging
into devices one by one, and to build a complete toolchain:

## What you will learn

| Chapter | What you will be able to do |
|---|---|
| **1. Python for networking** | Connect to devices with Netmiko, use JSON output, work in parallel |
| **2. Ansible for networking** | Write an inventory and playbooks, understand idempotency, protect secrets with Vault |
| **3. GitOps backups** | Back up every configuration to Git each day with a GitLab CI pipeline |
| **4. Secrets with HashiCorp Vault** | Store automation secrets in a central vault, with per-path permissions, versions and an audit log |
| **5. Break-glass account rotation** | Remove the default admin account, create a single break-glass account and rotate it automatically |
| **6. Naming conventions and IPAM** | Set naming rules and the addressing plan, and have the CI check them |
| **7. REST APIs** | Read and write through an API with GET, POST, PUT, PATCH and DELETE, understand status codes and explore the Swagger documentation |
| **8. NetBox, the source of truth** | Model your network in NetBox and derive inventories and configurations from it |
| **9. Arista AVD** | Generate, document and validate a fabric's configurations from a YAML model |

## Prerequisites

- The [Fundamentals](/en/courses/fundamentals) course; [dynamic routing](/en/courses/routing) helps for the AVD chapter.
- Being comfortable with a Linux terminal (`cd`, `ls`, editing a file).
- No Python or Ansible experience is needed: we start from the basics.

<Callout type="note">
Every script in this course is a real file, grouped in the `netops` lab: three Arista cEOS switches, an
inventory shared by Python and Ansible, and the chapters' scripts. The code shown in the chapters is
exactly the code you download. The comments inside the lab files are in French.
