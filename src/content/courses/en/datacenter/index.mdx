A corporate data center has little in common with the branch network of the Fundamentals course.
Hundreds of servers and virtual machines exchange far more with each other than with users, applications
move from one server to another without changing address, and several environments (production,
development, different customers) share the same infrastructure without ever seeing each other.

Classic designs, with their stretched VLANs and Spanning Tree, do not hold at that scale. This hop presents
the architecture that replaced them: a routed **spine/leaf fabric**, over which VLANs are carried in
**VXLAN**, with **BGP EVPN** as the control plane and **VRFs** to separate environments. It is the
architecture that tools such as Arista AVD generate.

## What you will learn

| Chapter | What you will be able to do |
|---|---|
| **VRFs** | Run several routing tables on one device, handle overlapping addresses, let two VRFs talk in a controlled way |
| **Spine/leaf architecture** | Explain why data centers left the three-tier model, size a fabric, build its eBGP underlay with ECMP |
| **The underlay in depth** | Choose between eBGP, OSPF and IS-IS, build an AS plan, move to BGP unnumbered, detect a failure in under a second with BFD, understand ECMP hashing and elephant flows |
| **Physical infrastructure** | Choose between top of rack, top of 3 racks and end of row, pick cables and optics, count a rack's ports, avoid airflow and fiber pitfalls |
| **Cabling and connectors** | Tell multimode from single-mode, LC from MPO, read an optic's name, choose between DAC, AOC and fiber, break out a port, respect the optical budget |
| **WDM multiplexing** | Carry several links over one fiber pair, choose between CWDM and DWDM, compute the budget of a link between two data centers |
| **Switch buffers** | Understand incast and microbursts, choose between shallow and deep buffers, use ECN, DCTCP and PFC, spot output discards |
| **VxLAN** | Carry a VLAN across a routed fabric, read a VXLAN packet, understand the limits of *flood and learn* |
| **EVPN, the control plane** | Distribute MAC and IP addresses over BGP, configure the anycast gateway and symmetric routing between VLANs and leaves |
| **EVPN multihoming** | Connect a server to two leaves without a peer-link (ESI-LAG), read type 1 and 4 routes, explain DF election, handle PXE installation with LACP fallback, choose between ESI-LAG and MLAG |
| **The border leaf** | Connect the fabric to the WAN, the Internet and firewalls, advertise external routes as type 5, send inter-VRF traffic through a firewall |
| **Disaster recovery and business continuity** | Set RTO and RPO with the business, choose a recovery strategy, prepare the recovery site's network and test the failover |
| **Data center interconnect (DCI)** | Choose the link and the interconnect mode, weigh the risks of a stretched VLAN, deploy EVPN between sites with gateways |
| **QoS in the data center** | Classify and mark traffic, configure queues, ECN and PFC, build a simple, consistent QoS plan |
| **The storage network** | Tell FC, iSCSI and NVMe-oF apart, design two paths with multipathing, align MTU 9000 end to end |
| **Networks for AI** | Understand a GPU cluster's traffic, size a rail-optimized fabric, configure a lossless RoCE network |
| **Operating a fabric** | Drain a device and put it in maintenance, upgrade a fabric without downtime, validate its state with ANTA, know what to monitor |

The chapters build on each other.
